---
title: "CORS"
description: "Enable CORS declaratively in techne.config.ts."
---

Set `cors` in `techne.config.ts`. Techne's HTTP adapter handles preflight
requests and adds the CORS headers itself:

```ts
// techne.config.ts
import { defineTechneConfig } from "@kaonashi-dev/techne/core";

export default defineTechneConfig({
  features: [AppFeature],
  port: 3000,
  cors: { origin: ["https://app.example.com"], credentials: true },
});
```

<Warning>
  `credentials: true` requires an **explicit** origin allow-list (a string or array). Combining it
  with a reflected or wildcard origin (`origin: true`, `origin: "*"`, or an omitted `origin`) is
  rejected at boot — that pairing would let any site read authenticated cross-origin responses.
</Warning>

## Options

| Option           | Type                            | Description                                   |
| ---------------- | ------------------------------- | --------------------------------------------- |
| `origin`         | `string \| string[] \| boolean` | Allowed origin(s); `true` reflects the origin |
| `methods`        | `string[]`                      | `Access-Control-Allow-Methods`                |
| `allowedHeaders` | `string[]`                      | `Access-Control-Allow-Headers`                |
| `exposedHeaders` | `string[]`                      | `Access-Control-Expose-Headers`               |
| `credentials`    | `boolean`                       | `Access-Control-Allow-Credentials`            |
| `maxAge`         | `number`                        | `Access-Control-Max-Age` in seconds           |

Native apps built with `createApp()` add CORS as a
[native plugin](/plugins/native-plugins).
