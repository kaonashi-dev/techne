## Install

```sh
bun add github:kaonashi-dev/techne
```

To pin a revision:

```sh
bun add "github:kaonashi-dev/techne#<tag-or-sha>"
```

Techne is not published to a registry yet. Use Bun as the runtime and package
manager. Elysia is installed with Techne; its native `t`, `status`, `problem` and
`Elysia` exports are available from the package root.

## TypeScript

```json
{
  "compilerOptions": {
    "target": "ESNext",
    "module": "Preserve",
    "moduleResolution": "Bundler",
    "strict": true,
    "skipLibCheck": true,
    "noEmit": true,
    "types": ["bun"]
  },
  "include": ["src/**/*.ts", "tests/**/*.ts"]
}
```

Install `typescript` and `@types/bun` as development dependencies. Native
applications require neither decorator flags nor metadata setup.

## Scaffold

```sh
bunx github:kaonashi-dev/techne new my-app
```

Inside the generated project, run `bun install` and `bun run dev`. The starter
includes a health endpoint, an HTTP test, strict type checking and Docker support.
See [project structure](/project-structure).
