## Status

Techne is still experimental. APIs may change quickly, some areas are
incomplete, and documentation will continue to evolve with the framework.

The latest release is **0.4.0**, which renamed the project to Techne — see
the [Changelog](/reference/changelog) and the [migration
guide](/reference/migrating). Recent work includes the outgoing HTTP
client, OpenTelemetry tracing and metrics, the security toolkit (headers,
CSRF, rate limiting, cookies), and the console-command subsystem.
