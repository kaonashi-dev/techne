title: "410 Gone"
description: "RFC 7807 problem document for HTTP 410 Gone."
---

This page documents the Techne RFC 7807 problem document for HTTP `gone` errors.

A `problem+json` response with `type` of
`https://github.com/kaonashi-dev/techne/blob/main/docs/errors/gone.md`
indicates the requested resource is Gone — it existed before but has been
permanently removed.

```json
{
  "type": "https://github.com/kaonashi-dev/techne/blob/main/docs/errors/gone.md",
  "title": "Gone",
  "status": 410,
  "detail": "<human-readable explanation>",
  "code": "<optional stable machine-readable code>",
  "instance": "<request URL path>",
  "requestId": "<uuid>"
}
```

For the full error contract and `HttpException` reference, see [Exceptions](/http/exceptions).
