Techne is a small wrapper around Elysia with feature-oriented project conventions
and application-owned resources. Its default API uses ordinary TypeScript
functions and native Elysia plugins.

## One HTTP execution model

`createApp()` returns an actual Elysia instance, with `precompile: true` by default.
Routing, schemas, hooks, errors and serialization are handled by Elysia. Techne
does not introduce a second HTTP dispatcher or request-time dependency container.

```ts
import { createApp } from "@kaonashi-dev/techne";

createApp()
  .get("/", () => ({ message: "Hello from Techne" }))
  .listen(3000);
```

## Explicit architecture

- **Composition root:** `app.ts` visibly wires dependencies and mounts features.
- **Feature factories:** take services as arguments and return Elysia plugins.
- **Plain services:** business logic works independently of HTTP or the framework.
- **Resource ownership:** `createResources` handles setup rollback and shutdown.
- **Native types:** route contracts are inferred from the actual Elysia chain.
- **Local reasoning:** developers and agents can follow imports and function
  arguments without scanning metadata, registries or decorators.

Start with the [quickstart](/quickstart), then read [native composition](/native-composition).
The executable reference is in `apps/native/` in the repository.

## Version and legacy boundary

Techne is experimental and pins `elysia@2.0.0-beta.1`. Examples use that version's
options-first routes and lifecycle names. Pin the Techne revision you depend on.

Existing decorator applications use `@kaonashi-dev/techne/legacy` or the historical
`/core` alias. The **Legacy reference** section documents their APIs and integration
protocol. See [migration](/native-migration) before changing an existing app.
